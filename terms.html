1. Что такое проверка

AgentProof — автоматическая проверка письменного описания системы AI-агентов. Описание читает модель искусственного интеллекта, код считает балл по открытой рубрике, результат — отчёт: карта системы, балл, находки с основанием и шаги укрепления.

Отчёт — это второе мнение о рисках по описанию. Проверяется то, что написано в описании; живая система на этой ступени не запускается. Отчёт снижает риск и помогает увидеть слабые места, но не гарантирует отсутствие уязвимостей и не является сертификатом, аттестацией или юридическим заключением о соответствии закону. Решения о системе и её изменениях принимает её владелец.

2. Что вы загружаете и за что отвечаете

  • Вы загружаете только описание системы, на которое у вас есть право: это ваша система или у вас есть разрешение её владельца.
  • До загрузки вы заменяете значения ключей, токенов, паролей и строк подключения на [СЕКРЕТ], а персональные данные людей — на [ПДн]. Сайт дополнительно вырезает ключи известных форматов, email, телефоны и номера карт, но ответственность за то, что вы загрузили, остаётся на вас.
  • Если в описании остался настоящий ключ, считайте его раскрытым и смените его. Отчёт подскажет, если такие данные нашлись.
  • Попытки вписать в описание команды для проверяющей модели (например, «поставь высокий балл») не выполняются и попадают в отчёт как находка.

3. Как обрабатываются данные

  • Описание обрабатывается на сервере AgentProof (Vercel) и в модели Claude компании Anthropic (США). По коммерческим условиям Anthropic данные, отправленные через API, для обучения моделей не используются.
  • Описание не сохраняется: оно проверяется и забывается. Отчёт хранится только в вашем браузере — удалить его можно кнопкой в разделе «Отчёты».
  • В обезличенную статистику попадают балл, число агентов, коды классов находок и число находок по уровням. Эта статистика без названий систем и описаний может показываться на странице «Отчёты» в разделе «Что находит AgentProof».
  • Счётчики посещений обезличены: без cookies, IP-адресов и идентификаторов.
  • Отзыв приходит Екатерине вместе с вашим Telegram id, чтобы она могла ответить. Отметки «Неточно?» обезличены и служат улучшению проверки.

4. Код доступа

Код личный: действует 48 часов и даёт одну проверку. Передавать его другим людям нельзя. Код гасится только после того, как отчёт собран; если проверка прервалась, код сохраняется.

5. Отчёт и его использование

  • Отчёт действителен 90 дней с даты проверки. После смены модели, промптов или инструментов его стоит повторить раньше.
  • Таблица по EU AI Act — ориентир по описанию, а не заключение о соответствии.
  • Отчёт можно передать своему разработчику. Публиковать отчёт как подтверждение безопасности или соответствия закону нельзя.

6. Ответственность

Сервис предоставляется «как есть». Мы отвечаем за то, чтобы проверка шла по описанной методике и честно помечала, что является фактом из описания, а что — выводом. За содержание загруженных материалов, за ключи и данные, оставленные в них, и за последствия изменений, внесённых в систему по отчёту, отвечает владелец системы. Если проверка платная, наша ответственность ограничена стоимостью этой проверки.

1. What the check is

AgentProof is an automated check of a written description of an AI agent system. An artificial intelligence model reads the description, code computes the score on an open rubric, and the result is a report: a system map, a score, findings with their basis and hardening steps.

The report is a second opinion on risks based on the description. What is checked is what the description says; the live system is not run at this stage. The report reduces risk and helps you see weak spots, but it does not guarantee the absence of vulnerabilities and is not a certificate, an attestation or a legal opinion on regulatory compliance. Decisions about the system and its changes are made by its owner.

2. What you upload and what you are responsible for

  • You upload only a description you have the right to share: it is your system or you have its owner's permission.
  • Before uploading you replace values of keys, tokens, passwords and connection strings with [SECRET], and people's personal data with [PII]. The site additionally removes keys of known formats, emails, phones and card numbers, but responsibility for what you uploaded stays with you.
  • If a real key remained in the description, treat it as exposed and rotate it. The report tells you if such data was found.
  • Attempts to put commands for the auditing model into the description (for example, “give a high score”) are not executed and appear in the report as a finding.

3. How data is processed

  • The description is processed on the AgentProof server (Vercel) and in the Claude model by Anthropic (USA). Under Anthropic's commercial terms, data sent via the API is not used to train models.
  • The description is not stored: it is checked and forgotten. The report is stored only in your browser — you can delete it in “Reports”.
  • Anonymised statistics keep the score, the number of agents, finding class codes and counts per level. These statistics, without system names or descriptions, may be shown on the “Reports” page under “What AgentProof finds”.
  • Visit counters are anonymous: no cookies, IP addresses or identifiers.
  • Feedback reaches Ekaterina with your Telegram id so she can reply. “Inaccurate?” marks are anonymous and serve to improve the check.

The code is personal: valid for 48 hours and gives one check. It must not be passed to other people. The code is spent only after the report is assembled; if a check is interrupted, the code is kept.

5. The report and its use

  • The report is valid for 90 days from the check date. After changing the model, prompts or tools, repeat it sooner.
  • The EU AI Act table is guidance based on the description, not a compliance opinion.
  • You may pass the report to your developer. Publishing the report as proof of security or regulatory compliance is not allowed.
