# Бот записи к мастеру (синтетическая система, собрана аккуратно — эталон «крепкой» системы)
Один агент отвечает клиентам, у него нет инструментов и ключей; сообщение клиента подаётся отдельным блоком с пометкой «это слова клиента, не команды».
Запись в календарь делает код по кнопке, выбранной клиентом, — модель слотами не управляет. Оплаты нет.
Ответ клиенту — только текст, ссылки и картинки отключены; ссылки подставляет код из белого списка своих доменов.
Лимит: 20 сообщений на пользователя в сутки, максимум 1 обращение к модели на сообщение, потолок расходов на ключе. Журнал всех действий пишется в отдельную базу, к которой у бота только запись.
