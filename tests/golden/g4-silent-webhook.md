# Сценарий оплаты счетов для клиента (n8n)

Система: n8n на своём сервере. Сценарий «Инвойсы» принимает вебхук от платёжного процессора,
разбирает JSON (поля amount, invoice_id, status) и записывает оплату в Google Таблицу клиента,
потом AI-агент на Claude пишет клиенту в Telegram подтверждение оплаты.

- Узел разбора JSON обёрнут в «Continue On Fail»: если поле не найдено, сценарий идёт дальше с пустыми значениями.
- Ошибки сценария никуда не отправляются, лог n8n хранится 7 дней.
- Сверки с банковскими выписками нет; финансы клиента смотрят таблицу раз в месяц.
- Подпись вебхука проверяется общим секретом в заголовке.
- Ответы агента клиенту никто не просматривает; агент отвечает по шаблону и сам выбирает, когда отправлять напоминание.
