# Контент-команда из трёх агентов (синтетическая система, дефекты заложены намеренно)
Агент «Исследователь» читает сайты конкурентов через инструмент fetch_url (любой адрес) и пишет сводку в общий файл notes.md.
Агент «Писатель» берёт notes.md целиком и пишет пост. Его вывод передаётся свободным текстом.
Агент «Публикатор» получает текст от Писателя и публикует его в Instagram и Telegram через API с полным доступом к аккаунтам; команду «опубликуй» он принимает от любого агента без проверки отправителя.
MCP-сервер «seo-helper» подключён из npm без закрепления версии; описание инструментов одобрено один раз при установке.
Память notes.md хранится между запусками, срок жизни записей не ограничен, источник записи не помечается.
