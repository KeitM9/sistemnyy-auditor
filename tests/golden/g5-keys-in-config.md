# Агент поддержки и автодеплой для интернет-магазина

Система: Langflow 1.7 на своём сервере, агент на GPT отвечает покупателям в Telegram и проверяет статус заказов через API магазина.

- Агент-помощник разработчика (Claude Code) работает в папке проекта и может читать все файлы, включая config/old/settings.prod.bak и .env.
- В репозитории на GitHub лежит старый файл config/test.yaml с ключом API магазина, ключ не отзывали.
- Публикация через GitHub Actions: workflow deploy.yml видит секреты OPENAI_API_KEY, SHOP_API_KEY и AWS_ACCESS_KEY_ID; добавлять файлы в .github/workflows могут все четыре участника, проверка изменений не обязательна.
- Обновления ставятся командой pip install -U без закреплённых версий.
- Вход в GitHub и хостинг — пароль и код из SMS.
- Использование ключей не журналируется, тревог нет; расходы OpenAI владелец смотрит раз в месяц в счёте.
