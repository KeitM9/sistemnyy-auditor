# Поддержка интернет-магазина: команда агентов на хостинге

Система: оркестратор на Claude запускает агентов поддержки, агент возвратов вызывает API платёжного сервиса.

- Оркестратор сам решает, сколько дочерних агентов запустить. Предела на их число и бюджета на запуск нет.
- Секрет вебхука оплат вписан буквально в 12 функций базы, в сценарий Make и в переменные хостинга. Записанного порядка смены нет. При смене в одном месте оплаты останавливаются.
- Агент возвратов при таймауте повторяет вызов до трёх раз. Ключа идемпотентности нет.
- Ключи не менялись с запуска.
